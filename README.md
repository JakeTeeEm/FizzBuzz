# FIZZBUZZ !!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!1



## Installation


### Linux

Requires *make* and some sort of C++ compiler (preferably g++) with libraries.

```bash
git clone https://github.com/JakeTeeEm/FizzBuzz.git
make
```

### Mac

Process is probably similar to linux, idk


### Windows

Use *Visual Studio Community* or some type of MSVC and just copy and paste the `src/main.cpp` file contents into your own `main.cpp`


## Run

Runs in terminal.

```bash
cd FizzBuzz
./fizzbuzz
```
